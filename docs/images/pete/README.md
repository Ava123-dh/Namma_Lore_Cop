The walk UI loads `images/pete/<id>.jpg` automatically and falls back to a
styled banner if the file is missing, so partial coverage is fine.

Use only images you have the rights to publish — photographs in the published
heritage walk guides are copyrighted (INTACH / British Library / individual
photographers) and are not bundled here.
